# Проект синтезатор

Браузерный синтезатор в виде математического плаката. Звук строится из формулы: пользователь вводит функцию f(x), она раскладывается в ряд Фурье, и коэффициенты ряда становятся формой волны осциллятора. Мелодию задаёт числовая последовательность a(n), а ударные — ритмы Евклида.

Экран разделён на три панели-плаката:

| Панель | Что делает |
| --- | --- |
| **01 / формула** | Поле для функции f(x) на отрезке [−π, π], оператор (∫∫f, ∫f, f, f′, f″), фильтр, эхо, тоника мелодии и выбор последовательности a(n) |
| **02 / геометрия** | График функции с касательной и закрашенной площадью под кривой, число гармоник ряда Фурье (от 1 до 64) и кроссфейдер между голосами |
| **03 / ритм** | Темп (черта знака √), три ряда ритмов Евклида E(k, 16) для kick, snare и hat, перегруз tanh(kx) и реверб |

Ручки нарисованы как части математических знаков: интеграл, скобки, корень, крест умножения. Все они работают мышью, пальцем и с клавиатуры (стрелки, PageUp/PageDown, Home/End).

## Математика внутри

- **Ряд Фурье.** Функция сэмплируется в 1024 точках, коэффициенты aₙ и bₙ считаются суммой Римана. Из них собирается `PeriodicWave` для Web Audio.
- **Производная и интеграл.** Считаются прямо в пространстве коэффициентов: производная умножает n-ю гармонику на n (звук становится ярче), интеграл делит на n (звук мягче).
- **Явление Гиббса.** Число гармоник можно уменьшать и видеть частичную сумму ряда внутри скобок на первой панели.
- **Ритмы Евклида.** k ударов максимально равномерно распределяются по 16 шагам.
- **Мелодия a(n).** Значения последовательности (например, n² mod 7) переводятся в ступени минорного лада.
- **Кроссфейдер.** Равная мощность: cos θ · f + sin θ · Δ, поэтому в середине громкость не проваливается.

## Управление с клавиатуры

| Клавиша | Действие |
| --- | --- |
| `Space` | Старт / стоп |
| `A W S E D F T G Y H U J K O L` | Ноты хроматической гаммы от C |
| `Z` / `X` | Октава вниз / вверх |
| `1` `2` `3` | Kick, snare, hat |

Звук включается после первого клика или нажатия клавиши: браузеры не дают запустить аудио без действия пользователя.

## Технологии

- **React 18** — интерфейс, все панели нарисованы на SVG
- **Tone.js** — аудиодвижок: осцилляторы, фильтр, дилэй, ударные, реверб, лимитер, транспорт
- **math.js** — разбор и вычисление формул, которые вводит пользователь
- **Vite** — сборка и dev-сервер
- **GitHub Actions + GitHub Pages** — автоматический деплой при пуше в `main`
- Шрифты **Instrument Serif** и **DM Mono** из Google Fonts

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, просмотр сборки: `npm run preview`.

## Структура

```
src/
├── App.jsx                  — состояние приложения, клавиатура, связь UI и звука
├── audio/engine.js          — весь звук на Tone.js
├── math/analysis.js         — ряд Фурье, операторы, ритмы Евклида, последовательности
├── components/
│   ├── FormulaPanel.jsx     — панель «формула»
│   ├── GeometryPanel.jsx    — панель «геометрия»
│   ├── RhythmPanel.jsx      — панель «ритм»
│   ├── glyphs.jsx           — ∫, скобки и √ в виде SVG-путей
│   └── svg.jsx              — универсальные ручки и кнопки с доступностью
└── styles.css               — цвета, шрифты, сетка панелей
```

## Какие ресурсы и ИИ использовались и для чего?

### WebStorm

IDE для работы с проектом.

### Claude

Аудиодвижок на Tone.js (цепочки эффектов, секвенсор, живая игра с клавиатуры), математика: разложение в ряд Фурье, производная и интеграл в пространстве коэффициентов, ритмы Евклида. Помощь с логикой React-компонентов, интерактивными SVG-ручками и их доступностью с клавиатуры, настройка деплоя на GitHub Pages.

### Cursor

Вёрстка панелей, подключение шрифтов, цветовые токены и базовые стили.

### Stackoverflow

Поиск ответов на вопросы по Web Audio API и работе с SVG-координатами.
