---
name: Math-poster instrument
description: |
  Интерфейс — швейцарский математический плакат из трёх вертикальных панелей.
  Математические знаки огромные и сами являются органами управления: точка внутри скобок —
  ручка, плечо креста — фейдер, черта радикала — слайдер темпа. Источник — референс-изображение
  пользователя («01 / FORMULA · 02 / GEOMETRY · 03 / SYMBOLS»).

colors:
  # панель 01 — формула
  paper: "#F2EDE3"
  ink: "#111111"
  coral: "#F26B4F"
  # панель 02 — геометрия
  mist: "#D9DEE3"
  blue: "#0B46F5"
  # панель 03 — символы
  night: "#0B0B0B"
  cream: "#F2EDE3"
  lime: "#D9F24A"
  # общее
  ink-mute: "rgba(17,17,17,0.45)"
  cream-mute: "rgba(242,237,227,0.45)"

typography:
  glyph:            # крупные буквы и числа: dx, A², 0.73, N
    fontFamily: Instrument Serif
    fontStyle: italic
    fontSize: 34–200px
    lineHeight: 1
  label:            # «01 / ФОРМУЛА», «темп», «эхо»
    fontFamily: DM Mono
    fontWeight: 300–400
    fontSize: 12–14px
    letterSpacing: 0.18em
    textTransform: lowercase (номера панелей — UPPERCASE)

shapes:
  # ∫, ( ), √, +, × рисуются SVG-путями, а не шрифтом: толщина и концы контролируются точно
  stroke-hairline: 1–1.5px   # окружности, касательные, оси
  stroke-bar: 3px            # линия слайдера
  glyph-bar: 30–56px         # плечи креста, черта дроби
  handle-dot: r 12–22px      # круглая ручка цвета акцента
  handle-square: 24px        # квадратная ручка (кроссфейдер)
  radius: 0                  # никаких скруглённых прямоугольников, только круги и прямые углы

layout:
  panels: 3 колонки на всю высоту окна (100vh), без отступов между ними
  viewBox: 420 × 800 на панель, масштабируется целиком (meet)
  gutter: 24px внутри панели
  mobile: панели идут друг под другом

rules:
  - Один акцентный цвет на панель: коралловый на кремовом, синий на серо-голубом, лаймовый на чёрном.
  - Акцент — только у того, что можно двигать (ручка, активное плечо, дуга значения).
  - Никаких теней, градиентов, карточек и рамок. Глубины нет — плакат плоский.
  - Подписи — маленький моноширинный шрифт с разрядкой, рядом с органом управления.
  - Значения — курсивом с засечками, как числа в формуле.
  - Пунктир со стрелками показывает, в каком направлении двигается ручка.
  - Штриховка (45°, 1px) — для площадей и «второстепенной» заливки.
  - Фокус с клавиатуры — пунктирный контур цвета акцента.
