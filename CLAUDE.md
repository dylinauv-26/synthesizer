# Синтезатор «Анализ»

Веб-синтезатор на React + Tone.js: звук строится из математических функций (ряды Фурье, производная, интеграл).

Визуальный стиль: @DESIGN.md

- Запуск: `npm run dev`, сборка: `npm run build`.
- `src/math/` — чистая математика без Tone.js; `src/audio/engine.js` — весь звук; `src/components/` — UI.
- Три панели-плаката: 01 формула (paper + coral), 02 геометрия (mist + blue), 03 ритм (night + lime). Знаки ∫ ( ) √ + × — SVG-пути и одновременно ручки.
